启动与运行

开机自动启动
写入当前用户的启动项（注册表 Run），不需要管理员权限。启动后直接在托盘待命。
启动时隐藏控制台窗口
双击 exe 后只在右下角托盘出现，不弹黑色命令行窗口。排查问题时可临时关掉。
安全模式（只记录不执行）
所有动作只写记录、不真正按键。第一次在新电脑上试可以开着。
允许关机 / 重启 / 睡眠
关掉后手机仍能关屏、锁屏，但电源菜单的关机/重启/睡眠会被拒绝，防误触。
全局热键
Ctrl+Alt+Q 弹出配对二维码，Ctrl+Alt+S 启停遥控服务。任何程序在前台都能用；改完重启程序生效。
语音回话
执行完给手机回一句「正在打开微信」之类的提示。关掉则只执行不吭声。
语音 LLM 兜底
本地规则没听懂时，把话交给大模型拆成动作再执行（联网，约 2-5 秒）。口述文字、闲聊不受影响。默认关。

版本与更新 —

启动时检查更新
启动 8 秒后后台查一次 GitHub，有新版本只在控制台和托盘气泡提示，不会自动下载安装。
GitHub 仓库
形如 yourname/pc-remote。优先读仓库的 Releases（取最新 tag），没有 Release 时读仓库根目录的 version.json。改完点「保存仓库」。

记录

记录同时写入文件
在 exe 同目录 logs\ 下按天存 key-*.log / voice-*.log，方便事后翻查。
内存保留条数
界面里最多显示多少条，超出自动丢弃最早的。不影响落盘文件。

网络

遥控服务端口
手机连的端口，默认 8765。改了之后手机上的电脑记录要重新扫码配对。
管理界面端口
本控制台端口，默认 8766，只绑 127.0.0.1。改动需重启程序生效。
